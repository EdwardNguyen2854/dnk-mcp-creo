# Documentation assets

These images are original artwork for this project and are licensed under the
same Apache License 2.0 as the repository.

| File | Used by | Description |
|---|---|---|
| `pulley-hero.png` | README | Isometric drawing sheet of the six-spoke pulley built by the features pack |
| `architecture.png` / `.mmd` | README, docs | MCP clients → TypeScript server → OTK bridge → Creo |
| `tool-packs.png` / `.mmd` | docs | Opt-in tool packs and their counts |
| `write-path.png` / `.mmd` | README, docs | Admit → guard → apply → verify → audit write path |
| `build-chain.png` | docs | The three drawing states of the showcase part |

The `.mmd` files are the editable Mermaid sources for the diagrams. The PNG
renders use a light theme with graphite ink (`#16232e`), teal accents
(`#0d6b8a`), and Segoe UI. Re-render them with any Mermaid-capable editor or the
Mermaid CLI.
